# Design Source Archives

This directory stores historical and exploratory design assets, vector prototypes, concept sketches, and branding proposals that are preserved for reference but are **not** bundled or served with the production web application (`health-kicks-frontend`).

## Contents

- `logos/`:
  - Historical logo variations and concept exploratory files (`concept_a_vector.svg`, `concept_b_vector.svg`, `concept_c_vector.svg`, and associated JPG/PNG raster mocks).
  - Prior favicon and app icon variations before brand unification around `#1D5CF5` and `health-kicks-frontend/public/favicon.svg`.
